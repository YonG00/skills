# 聊天模式提示词：Conversation Synthesis

> **用法**：在一段**已经聊完的对话末尾**贴出下面任意一个方案。模型手里已经有整段对话，**不需要再粘贴一遍**。
>
> **执行方式**：整件事分 **7 个阶段**，一次只做一个。每个阶段结束它都会停下并打印 `⏸ 阶段 N 完成`；你检查没问题就说「继续」，有问题就直接说改什么。
>
> **⚠️ 同步义务**：本文件是 `SKILL.md` 的**派生副本**。改完 skill 后按文末 [同步清单](#与-skillmd-的同步清单) 检查这里是否过期。**提示词过期不会报错，只会让模型悄悄按旧规则走。**

## 方案 A：联网可读链接（推荐）

适用：聊天模式**能访问网页**。规范从 GitHub 现读，永远是最新版；提示词本身只管**阶段编排**，所以很短。

```
先完整读取这两份规范，读完再按它们处理**上面这段对话**：

1. https://raw.githubusercontent.com/YonG00/skills/main/conversation-synthesis/SKILL.md
2. https://raw.githubusercontent.com/YonG00/skills/main/conversation-synthesis/references/conversation-to-outline.md

读完不要复述规范内容。按下面的【分阶段契约】执行。

════ 分阶段契约（最高优先级）════
整件事分 7 个阶段，一次只做一个。

· 每次回复的**第一行**必须是：`【阶段 N/7：名称】`
· 每次回复的**最后一行**必须是：`⏸ 阶段 N 完成，等你说「继续」`
  打印后立即停止，不得开始下一阶段、不得提前输出后续阶段的内容。
· 我说「继续」→ 进入下一阶段。
· 我说「跳过」→ 跳过当前阶段。
· 我说「回到阶段 N」→ 回退重做。
· 我直接指出问题时，只改那个问题，改完重新打印本阶段的完成行。
· **一次回复跨越两个阶段 = 错误**：立刻停止，只保留当前阶段的内容。

阶段 1｜骨架
  只输出四样：问题链 + 判断变化点（原判断 → 触发物 → 新判断）+ 六列骨架表
  + 信息资产归属表。**一篇正文都不许写。**
  · 判断变化点为 0 → 直接说「这段对话目前只是收集了资料，不构成文章」，
    说明缺什么，然后停在这里，不要往下走。
  · 资料很多 → 先给三层清单（核心信息 / 有价值资源 / 边缘信息）让我决定取舍，别自己定。
  · 早期对话已不在你的上下文里 → 直接说，不要凭印象补。

阶段 2｜初稿
  按骨架逐节写出完整初稿。内容先落下来，不追求文字打磨。
  · 每节都要能回答「为什么这一节在这里」。
  · 事实 / 用户判断 / 推演 三者分得清；我后续修正过的说法一律用最新版。
  · 你自己产生的观点不许写进我的第一人称。
  · 内部先想好 ≥5 个候选标题，但这一阶段不要列出来。

阶段 3｜论证加固
  不改文字，只加固内容。对每个核心判断逐条追问，并给出「原文 → 建议补充/修正」：
  · 什么情况下这个判断不成立？有没有明显反例或限制要写出来？
  · 是不是二元对立？有没有中间态？
  · 系统在奖励什么、惩罚什么？这是机制解释，还是已被证明的因果？
  · 纸面平等 ≠ 实际可用：谁掌握信息、谁承担举证、谁有专业人员、谁耗得起？
  · 这个方案会制造什么新问题？（隐私 / 监控 / 形式主义 / 合规成本 / 新的不平等）
  · 建议有没有落到机制：谁负责、数据从哪来、多久一次、异常怎么办？
  输出一张「论证加固清单」，每条标明是「已补进正文」还是「建议你再决定」。

阶段 4｜语言与风格
  只做表达层面，不新增内容。逐条给「原文 → 改后 → 为什么」，最后给一张改动清单。
  · 消除 AI 味：本质上 / 真正 / 核心 / 值得关注 / 重新定义 / 范式 / 赋能 / 从某种意义上
  · 压金句密度：单句成段、极短反问、排比、「不是 X，而是 Y」、过量粗体
  · 排版：**禁止「标签行 + 内容行」**；多个短语能写成一句就合成一行
  · 去掉结构化成瘾：每段三点、每节都总结
  · 该具体的地方要具体（有人、有动作、有成本、有后果），不靠"说白了/本质上/其实就是"
  · 该锐利的地方要锐利（找到真正起作用的变量，不停在表面现象）
  · **默认只输出改动部分 + 清单，不要重发全文**；我说「给我全文」再发。

阶段 5｜证据与链接
  · 逐项列出可核验内容（数字 / 法律 / 政策 / 研究 / 国外制度 / 机构定义）→ 对应来源
  · 需要补链接的直接补在**第一次出现的位置**，不要堆到文末"参考资料"
  · 检查有没有把「相关」写成因果（导致 / 造成 / 证明 / 必然 / 就是因为），该降级的降级
  · **核实不了的，单独列「缺来源」清单**。不要编造链接，也不要给个假出处凑数
  · 输出：来源对照表 + 缺来源清单 + 修改后的相关段落

阶段 6｜结尾与问题升级
  · 回答：最初在问什么？哪个判断被修正？现在最可信的是什么？还不知道什么？下一步该验证什么？
  · 如果开头用了具体场景，用全文的新理解重新解释它，不能原样重复
  · 删掉「这个问题值得进一步思考」这类没结束的结尾
  · 输出：新结尾段 + 一句说明它如何回应开头

阶段 7｜标题候选与成稿
  · 先给 ≥5 个候选标题，每个标注它含哪三要素（讨论对象 / 核心矛盾 / 信息增量），
    推荐一个并说明理由。
  · 然后输出**完整成稿**。
  · 最后跑七项审计，逐项给结论：
    证据 / 用户真实性 / 对话完整性 / 结构 / 文章形态 / 逻辑强度 / 结尾
  · 我选定标题后，你再替换标题输出最终版。

现在开始阶段 1。
```

## 方案 B：自包含（不能联网时用）

规则全部内联，按**它被用到的阶段**组织，不做无谓重复。

```
以上是我们完整的对话。现在把它整理成一篇有观点的文章——不是复述聊天记录，
也不是把资料排版整齐。

════ 分阶段契约（最高优先级）════
整件事分 7 个阶段，一次只做一个。

· 每次回复的**第一行**必须是：`【阶段 N/7：名称】`
· 每次回复的**最后一行**必须是：`⏸ 阶段 N 完成，等你说「继续」`
  打印后立即停止，不得开始下一阶段、不得提前输出后续阶段的内容。
· 我说「继续」→ 进入下一阶段。我说「跳过」→ 跳过。我说「回到阶段 N」→ 回退重做。
· **一次回复跨越两个阶段 = 错误**：立刻停止，只保留当前阶段的内容。

════════════ 阶段 1｜骨架 ════════════
这一轮只输出：问题链 + 判断变化点 + 六列骨架表 + 信息资产归属表。
**一篇正文都不许写。**

先看这段对话能不能写成文章。把判断变化点找出来：
  原判断 → 触发物 → 新判断
· 找到 ≥1 个 → 继续。
· 找到 0 个 → 明确告诉我「这段对话目前只是收集了资料，不构成文章」，说明缺什么，
  然后停在这里，**不要硬凑一篇看起来完整的探索文章**。

骨架怎么做：
1 **论元**：把对话切成最小的主张单元，每个标类型与状态。
  类型：事实 / 用户判断 / 推演 / 假设 / 问题 / 证据 / 反例 / 未解决
  状态：现行 / 已被我修正 / 已废弃
  ⚠️ 我后来改过说法的地方，旧表述一律标「已被修正」，正文只能用最新版。
  ⚠️ 你自己产生的推演不许标成「用户判断」。
2 **问题链**：把「问题」类论元连成 Q0 → … → 当前问题，标出每个问题被什么回答。
  两个问题之间没有回答连接 → 链是断的：要么漏了论元，要么这段对话没推进。
3 **判断变化点**：就是上面那个三元组。这是文章真正的骨架节点。
4 **章节**：一节 = 一次判断变化 + 支撑它的证据。逐节能说清
  「原来以为 X，因为 Y，现在认为 Z」。一节含两次独立变化 → 拆开。
  删掉某节后中心问题仍成立 → 它不属于主线。
5 **中心问题**：在 1–4 之后才写。答案应比最初的问题**更准或更窄**；
  和最初一样 → 说明对话没推进。
6 **资产归属**：每个论元、每项搜到的资料（数据/法律/论文/案例/工具/网站/渠道/关键词）
  各归一处：某节正文 / 核心证据 / 重要补充 / 反例限制 / 后续资源 / 边缘 / 已废弃
  **总数必须守恒**——任何一项没有归属都要写明理由。
  允许的理由只有：不相关 / 重复 / 来源差 / 已过时 / 有更好的来源 / 我不要。
  **「删了以后文章更顺」不是理由。**
7 **骨架表**，就这六列：
  | 节 | 这一节回答什么 | 判断变化（原→现） | 支撑证据 | 源位置 | 这一节不写什么 |

资料很多时 → 先给我三层清单（核心信息 / 有价值资源 / 边缘信息），
让我决定：保留 / 删除 / 放正文 / 只留链接 / 放附录。**别自己定。**
只有我说「直接写、不用问我」，才按这个优先级办：
推动问题变化的信息 > 支撑核心判断的资料 > 可继续使用的工具/渠道 > 一般背景。

早期对话已不在你的上下文里 → **直接说**，不要凭印象补细节。
凭记忆编出来的用户原话，比缺一段更糟。

════════════ 阶段 2｜初稿 ════════════
按骨架逐节写出完整初稿。内容先落下来，不追求文字打磨。

**不替我说话**
· 不能把「我怀疑」写成「事实证明」，不能把「我在考虑」写成「我决定了」。
· 你自己的观点不许塞进我的第一人称。
· 不确定就保留：可能 / 我更倾向于 / 至少说明 / 现有证据支持 / 目前还不能证明。
· 保留具体：时间、地点、动作、当时想到什么、后来什么变了。
  不要把具体经历润色成空泛的"高级表达"。
· 我的个人经历是**问题入口**，不是社会统计——不能从「我经历过」跳到「大家都这样」。

**结构**
· 章节跟着**问题变化**走，不按资料分类（✗ 数据 / 法律 / 国外案例 / 论文）。
· 每一节都要能回答「为什么这一节在这里」。
· 小标题必须独立可读。✗「真正的问题」「另一种可能」 ✓「为什么 X 会产生 Y？」
· 新概念从问题里长出来，不要突然塞一堆术语。
· 内部先想好 ≥5 个候选标题，但这一阶段**不要列出来**。

**三类内容分得清**：事实 / 用户判断 / 推演 / 假设 / 未解决 —— 不要混在一起说。

════════════ 阶段 3｜论证加固 ════════════
不改文字，只加固内容。对每个核心判断逐条追问，输出「论证加固清单」：
· 依据是什么？是数据、法律、经历、研究还是推演？
· 所以呢？它改变了哪个问题？真正想说什么？（只能写"很重要"就是没想透）
· 什么情况下这个判断不成立？有没有明显反例或限制要写出来？
· 是不是二元对立？有没有中间态？
· 系统在奖励什么、惩罚什么？这是机制解释，还是已被证明的因果？
· 纸面平等 ≠ 实际可用：谁掌握信息、谁承担举证、谁有专业人员、谁耗得起？
· 这个方案会制造什么新问题？——**副作用检查**：隐私 / 监控 / 形式主义 /
  数据造假 / 合规成本 / 权力滥用 / 新的不平等
· 建议有没有落到机制：谁负责、数据从哪来、多久一次、谁能看、异常怎么办？
每条标明是「已补进正文」还是「建议你再决定」。

════════════ 阶段 4｜语言与风格 ════════════
只做表达层面，不新增内容。逐条给「原文 → 改后 → 为什么」，最后给一张改动清单。

· **禁止「标签行 + 内容行」**：
  ✗ 如果： / A > 0 / 那么： / 增加： / P(y|x)
  ✓ 当 A > 0 时提高 P(y|x)，当 A < 0 时降低 P(y|x)。
· 长文用**连续 prose**。多个短语能写成一句话，就不要拆成大量单独行。
· 列表只用于步骤/清单/对比/选项/分类，不用来制造节奏或强调。
· 控制金句密度：不要每段都像海报。避免过量粗体、单句成段、极短反问、排比、
  「不是 X，而是 Y」。默认节奏：事实 → 解释 → 推理 → 判断 → 必要时强调。
· 少用：本质上 / 真正 / 核心 / 值得关注 / 重新定义 / 范式 / 赋能 / 从某种意义上。
· **AI 感不是某个词，而是所有段落都被加工得过于整齐**（每段三点、每节都总结）。
· 接地气靠**具体**（有人、有动作、有成本、有后果），不靠"说白了/本质上/其实就是"。
· **锐利** = 找到真正起作用的变量：不停在「机会没人发现」，追问「还是根本没人买？」
· **有洞见** = 把原本分开的信息连起来，让**问题本身发生变化**——不是写一句漂亮金句。
· 反讽只能建立在事实矛盾上，不许为了尖锐去猜别人动机。
· 犀利 ≠ 武断：有证据就直接，没证据就留边界，不要为气势提高因果强度。
· 直接说：`问题在于……`，不要`在进一步对这一问题进行分析以后，我们可以发现……`
· **默认只输出改动部分 + 清单，不要重发全文**；我说「给我全文」再发。

════════════ 阶段 5｜证据与链接 ════════════
· 逐项列出可核验内容（数字 / 法律 / 政策 / 研究 / 国外制度 / 机构定义）→ 对应来源。
· 来源优先级：法律原文·政府文件·官方统计 > 原始论文 > 权威国际组织 >
  研究机构 > 可靠媒体 > 行业媒体 > 社区/个人经验。
  社区只用来证明「有人这样讨论」，不承担核心事实。
· 需要补链接的直接补在**第一次出现的位置**，不要全堆到文末"参考资料"。
· **相关 ≠ 因果。** 证据不够就降级表达。特别检查：导致 / 造成 / 证明 / 必然 / 就是因为。
· 观点不需要假装成文献——我的经历、价值判断、明确标注的推演，不用硬挂链接。
· **核实不了的，单独列「缺来源」清单**。不要编造链接，也不要给个假出处凑数。
· 输出：来源对照表 + 缺来源清单 + 修改后的相关段落。

════════════ 阶段 6｜结尾与问题升级 ════════════
· 不是重复摘要。至少回答：最初在问什么？哪个判断被修正？现在最可信的是什么？
  还不知道什么？下一步该验证什么？
· 如果开头用了具体场景，可以回环，但要用全文的新理解**重新解释**它，不能原样重复。
· 最后一段要真的结束。✗「这个问题值得进一步思考。」
· 输出：新结尾段 + 一句说明它如何回应开头。

════════════ 阶段 7｜标题候选与成稿 ════════════
· 先给 ≥5 个候选标题，每个标注它含哪三要素（**讨论对象 / 核心矛盾 / 信息增量**），
  推荐一个并说明理由。不要只追求情绪、文艺、猎奇、学术感。
· 然后输出**完整成稿**。
· 最后跑七项审计，逐项给结论：
  1 **证据** — 重要数字/法律/政策/研究都有来源？相关没被写成因果？
  2 **用户真实性** — 有没有替我表态？有没有把旧措辞写回来？
  3 **对话完整性** — 重要资源、渠道、案例、链接有没有莫名消失？
  4 **结构** — 只读标题能看懂路线？每节为什么在这？有没有可以删掉而不影响文章的章节？
  5 **文章形态** — 有没有一词一行 / 不必要列表 / PPT 感 / 金句过密？
    有没有"听着很对、其实没信息"的空话？
  6 **逻辑强度** — 事实/判断/推演混了吗？找过反例和中间态吗？
    **换成技术、职业、学习、研究等其他领域，这套逻辑还成立吗？**
  7 **结尾** — 问题升级了吗？收住了吗？
· 我选定标题后，你再替换标题输出最终版。

现在开始阶段 1。
```

## 七个阶段对应什么

| 阶段 | 对应 `SKILL.md` | 交付物 | 你检查什么 |
|---|---|---|---|
| 1 骨架 | §一 + `conversation-to-outline.md` | 问题链 / 判断变化点 / 骨架表 / 资产归属表 | **判断变化那一列是不是真的**——空的或牵强就该停，别往下走 |
| 2 初稿 | §二 + §六 | 完整初稿 | 有没有替我表态、有没有用我纠正过的旧说法、章节顺序对不对 |
| 3 论证加固 | §五（第 29–35 条） | 论证加固清单 | 反例、中间态、副作用有没有被认真找过 |
| 4 语言与风格 | §七（第 40–47 条） | 改动清单 + 改后段落 | AI 味、金句密度、标签行、该具体/该锐利的地方 |
| 5 证据与链接 | §四（第 23–28 条） | 来源对照表 + **缺来源清单** | 有没有编造出处；因果强度有没有虚高 |
| 6 结尾 | §八（第 48–50 条） | 新结尾段 | 问题有没有升级，还是又总结了一遍 |
| 7 标题与成稿 | §六 + §十 | ≥5 候选标题 + 成稿 + 七项审计 | 标题与正文是否匹配；审计结论是否诚实 |

**为什么标题放最后**：`SKILL.md` 第 36 条要求在写稿**前**内部产生候选标题，所以阶段 2 已经内部想过一轮；但**呈现给你挑选**放在最后更准——那时文章内容已经定了，能判断标题是否真的匹配。

**为什么阶段 3 单独拆出来**：你原来的清单里没有它，但 skill 有一整部分（第 29–35 条）是这个——反例、中间态、系统激励、资源不对称、制度副作用、建议落到机制。少了它，文章会流畅但**经不起追问**。

## 用法要点

| | |
|---|---|
| **贴在哪** | 对话**末尾**。模型手里已有整段对话，不要再粘一遍 |
| **怎么推进** | 每个阶段末尾它会打印 `⏸ 阶段 N 完成`。检查没问题 → 说「继续」 |
| **发现问题** | 直接说改什么，不要自己动手改；它会改完重新打印本阶段完成行 |
| **想跳过** | 说「跳过」（例如你不需要补链接，就跳过阶段 5） |
| **想回退** | 说「回到阶段 3」 |
| **要看全文** | 阶段 4 默认只给改动部分。说「给我全文」它才重发 |

**发现它越界时**（一次做两个阶段、或阶段 1 就写正文），回一句：

```
停。越界了。只保留【阶段 N】的内容，删掉后面阶段的，重新打印完成行。
```

**如果它在阶段 1 说「这段对话写不成文章」**——那是**正确行为**，不是失败。说明这段对话目前只是在收集资料。可以让它告诉你缺什么，再决定是继续聊，还是让它改成一份**资料整理**（那是另一种交付物，不是探索文章）。

## 已知漂移与纠偏

| 漂移现象 | 一句话纠偏 |
|---|---|
| 一次做多个阶段 | 「停，越界了，只保留阶段 N」 |
| 阶段 1 直接写正文 | 「停，阶段 1 只给骨架」 |
| 骨架的「判断变化」列是空的或牵强 | 「判断变化点重新找：原判断 → 触发物 → 新判断」 |
| 阶段 3 只夸文章好，没找出反例 | 「每个核心判断都问：什么情况下它不成立？」 |
| 阶段 4 重发了全文 | 「只给改动部分和清单」 |
| 阶段 5 编了个看起来像的出处的链接 | 「核实不了的列进缺来源清单，不要编」 |
| 出现标签行 + 内容行 / 一词一行 | 「排版：标签和内容同行，短句凑一行」 |
| 结尾是"值得进一步思考" | 「结尾做问题升级，不要机械总结」 |
| 忘记打印阶段标记 | 「每轮第一行标阶段，最后一行打印完成行」 |
