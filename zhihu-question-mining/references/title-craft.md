# 标题：从具体痛点切进去

> **来源**：规则提炼自一次真实的六轮修改记录（用户连续退回五版）。原始对照见 `references/worked-example.md`。
>
> **一句话原则**：让**具体的东西**先出场，把抽象留给描述。

---

## 1. 五条判据

### 1.1 具体对象优先

产品名、作品名、真实场景，永远比抽象概念更抓人。

| ✗ 抽象 | ✓ 具体 |
|---|---|
| 强 IP 作品失去核心创作者后，质量和风格可能迅速变化 | **《凡人》** 这么大的 IP，怎么换几个人以后，味道就能差这么多？ |
| AI 怎样才能真正融入日常生活 | AI 都这么厉害了，为什么**平时用起来**还是这么麻烦？ |

### 1.2 反差结构

「A 能，B 为什么不能」这类**把两个事实并排放**的句式，天然自带张力。

- ✓ 为什么**微信打电话能**直接用蓝牙耳机，**AI 对话反而不行**？
- ✓ AI **都这么厉害了**，为什么**平时用起来还是这么麻烦**？
- ✓ 想法太多、什么都想研究，**是好事还是**在浪费精力？

> 反对照的说法是平铺直叙：「为什么 AI 助手不能像微信电话一样用蓝牙耳机对话？」——信息一样，但没有落差。

### 1.3 动词和人话

| ✗ 名词化 | ✓ 人话 |
|---|---|
| 普通租房环境里，怎样才能**系统地治理蟑螂**？ | 蟑螂到底**怎么弄最有效**？ |
| 怎样把好奇心**转化成真正的成果**？ | 想法太多、什么都想研究，是好事还是**在浪费精力**？ |
| 怎样让自己快速进入**高效决策状态**？ | 为什么**我刚起床**的时候特别难做决定？ |

### 1.4 允许一点情绪

知乎提问不是论文标题。带情绪的句子更真实，也更容易被点开。

- ✓ 蟑螂到底怎么弄最有效？**难道人类到现在还没一套靠谱办法吗？**
- ✓ 有想法到底该不该说出来？**会不会说多了反而把自己的东西都送人了？**

情绪要来自**真实的困惑或不满**，不是制造出来的惊讶。

### 1.5 一行以内，不标题党

- 尽量一行，超过一行就砍
- **不写**：浅析、探析、成因、初探、该如何、我们应当
- **不做**：虚假悬念（「看完你就懂了」）、夸张断言（「所有人都错了」）、蹭无关热点
- 标题里的问号**最多一个**（连续两问会显得像营销号）

## 2. 同一批话题的三版演进（真实记录）

左边是「整理感太重」的一版，右边是用户最终认可的「接地气」一版。

| # | 一稿（整理感重） | 三稿（中间版） | **定稿（接地气）** |
|---|---|---|---|
| 1 | 为什么 AI 助手不能像微信电话一样通过蓝牙耳机直接对话？ | 为什么 AI 助手不能像微信电话一样直接用蓝牙耳机对话？ | **为什么微信打电话能直接用蓝牙耳机，AI 对话反而不行？** |
| 2 | 决策力可以训练吗？怎样让自己快速进入高效决策状态？ | 人的决策力到底要怎么训练？早上是不是本来就不适合做复杂决策？ | **人的决策能力能练出来吗？为什么我刚起床的时候特别难做决定？** |
| 3 | 想法太多、兴趣太广的人，怎样把好奇心转化成真正的成果？ | 想法太多、问题太多的人，应该怎么把这种特点用好？ | **想法太多、什么都想研究，是好事还是在浪费精力？** |
| 4 | AI 怎样才能真正融入日常生活，而不是"有问题时拿手机问一下"？ | AI 到底怎样才能真正融入日常生活，而不是有问题时才拿手机出来问？ | **AI 都这么厉害了，为什么平时用起来还是这么麻烦？** |
| 5 | 公开分享自己的想法，会让个人受益，还是在主动放弃"信息差"？ | 普通人有想法，到底应该公开分享，还是应该藏着？ | **有想法到底该不该说出来？会不会说多了反而把自己的东西都送人了？** |
| 6 | 普通租房环境里，怎样才能系统地治理蟑螂？ | 蟑螂到底应该怎么处理？有没有一套真正有效的方法论？ | **蟑螂到底怎么弄最有效？难道人类到现在还没一套靠谱办法吗？** |
| 7 | 为什么强 IP 作品失去核心创作者后，质量和风格可能迅速变化？ | 为什么很多作品一旦失去"灵魂人物"，整个味道都变了？ | **《凡人》这么大的 IP，怎么换几个人以后，味道就能差这么多？** |

## 3. 从对照里提炼的六个改法

排在前面的是**收益最大**的。

| 改法 | 例 |
|---|---|
| **1. 把具体对象提到标题** | 「强 IP 作品」→「**《凡人》**」；「AI 能力」→「**豆包/元宝/DeepSeek**」 |
| **2. 抽象名词换成生活说法** | 「**信息差**」→「**把自己的东西都送人了**」 |
| **3. 加反差/对比结构** | 「AI 为什么不能 X」→「**微信能 X，AI 反而不行**」 |
| **4. 名词化改成动词** | 「**系统地治理**蟑螂」→「蟑螂到底**怎么弄**最有效」 |
| **5. 去掉书面术语** | 「**高效决策状态**」→「**我刚起床的时候**特别难做决定」 |
| **6. 短句切分** | 长句 + 多个限定 → 两个短句，或一个短问 + 一个反问 |

### 第 7 个话题的完整教训

用户对中间版的评价原话：

> 「5. 为什么很多作品一旦失去"灵魂人物"，整个味道就变了？**应该提到《凡人》这个作品吧，问题提问不够尖锐，不够吸引关注**」

修改者的自述：

> 「第 7 个**抽象层级提得太早**，把《凡人》这个最能吸引人点进去的具体对象藏掉了。我建议把标题先从'具体作品'切进去，再在描述里把问题上升到更大的讨论。」

**所以不要反过来**：不是「先抽象，再举例」，而是**「标题给具体，描述做升华」**。

## 4. 生成标题时的做法

1. **每个单元先生成 3–5 个候选**，分别用不同角度切（场景 / 反差 / 具体对象 / 情绪）
2. **逐个过五条判据**，写下每个候选被淘汰的原因
3. **推荐一个**，说明它为什么比其他的好
4. 如果用户已经认可了某个标题，**只改他指出的问题**，不要顺手重写全部

> **不要**把所有候选都堆给用户让他选。给一个推荐 + 一句理由，用户不满意会自己说。

## 5. 自检

- [ ] 标题里有没有**具体的东西**（产品名 / 作品名 / 可复述的场景）？
- [ ] 有没有**反差**，还是平铺直叙？
- [ ] 念一遍——像不像**一个普通人**会这么问？
- [ ] 有没有**书面套语**（浅析 / 系统治理 / 转化 / 高效…状态）？
- [ ] 问号是不是**只有一个**？有没有变成营销号式连问？
- [ ] 有没有夸大或虚假悬念？
- [ ] 一行放得下吗？
- [ ] **标题和描述匹配吗？**——标题承诺的那个矛盾，描述里真的在问它吗？
