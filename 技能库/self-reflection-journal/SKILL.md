# 自我思考日志

把零散表达整理成一份以后读得懂、还能接着想的日志。旧名称为 `zhihu-question-mining`，本版已取消平台提问定位。

默认产出一篇按主题组织的思考日志；不是逐条加工成提问，也不替作者把尚未想明白的事情写成成熟结论。只有用户明确要研究、建议或回答问题时，才扩展到那些任务。

## 保真与边界

- 保留第一人称、具体对象、经历、动机、情绪与犹豫。原话中的“可能”“我怀疑”“还没想明白”不能改成定论；“我觉得”可以保留。
- 不替用户补充他没说过的经历、动机、论证、计划或答案。区分用户原有的发散与整理者新想到的联想；后者默认不加入，有要求才单列为“整理者补充”。
- 情绪、普通日常、没讲完的话和互相矛盾的想法也有记录价值，不因没有主张或核心矛盾而删除。疑问不一定有反差，点子不一定有方案。
- 删口头填充和无信息重复，但保留改变判断的重复、语气和自我修正。不同时间的变化按先后交代，不静默揉成同一个立场。
- 同一条思路存疑则合，用段落表达它的侧面。只有独立经历或思路明显改变才分节；“另外”不是拆分依据。已认可的划分不要再拆。
- 标题准确具体，允许陈述句和疑问句；不追求流量或刻意反差，不用占位标签交付。

## 工作方式

### 1. 读取与转写核对

有稿子就以稿子为整理输入；同时有录音时，用录音核对可疑处。只有录音时，先使用可用的转写工具；不能转写就如实说明缺少的条件，不冒充已经听过。

检查专有名词、否定词、数字和会改变意思的断句。明显标点和重复可直接修；不能确定的关键字保留原文并标“待确认”。外部搜索可以检查候选名称，不能仅凭搜到某词就认定用户说的是它。不要因为个别词未确认而阻塞无关部分。详见 [转写保真](references/transcript-fidelity.md)。

### 2. 提炼内容，连接思路

在工作底稿中给有效内容记录源位置（音频时间戳或稿子段落），按实际内容识别以下类型；它们可以共存于同一节，不是互斥分类，也不必凑齐：

| 类型 | 保留什么 |
|---|---|
| 问题 | 我在困惑什么、为什么开始问、仍卡在哪里 |
| 想法与点子 | 当前判断、观察、设想、尝试方案及其不确定程度 |
| 经历与状态记录 | 发生了什么、具体感受、当时状态；没有结论也保留 |
| 发散与延伸 | 从一个念头联想到什么、哪里暂时中断、还想接着看什么 |

先按原来的思路推进顺序整理，跨段重复可归并。记录相邻想法的连接，不强行制造因果。不同日期、话题明显无关时可分成数篇短日志；不为了数量把同一想法切碎。操作细节见 [主题与思路](references/topic-splitting.md) 和 [想法、记录与发散](references/ideas.md)。

### 3. 写成日志

用自然的第一人称段落串起“触发场景 → 当时想到的内容 → 尚未解决或后来变化的部分”；只写素材中实际存在的环节。每节可自然混合提问、想法和记录，用少量小标题帮助回看，不要求四类分成四张清单。

保留口语的个人感，不逐字堆口头填充，也不写成研究报告。原稿只有一句就保留短条目；未完的片段注明“想到这里暂时停住”，不补齐。没有新结论就自然结束；不强制总结、升华、行动清单或疑问句收尾。详见 [行文风格](references/description-style.md) 和 [标题](references/title-craft.md)。

### 4. 交付与博客用途

- 默认交付 Markdown 日志正文，可直接留档或继续编辑；日期取素材明确的日期，未提供则省略或注明“整理于某日”，不虚构经历日期。
- 待确认词、必要的删并说明与来源对照放在正文之后，明确标为“整理备注（不属于发布正文）”。不把内部编号、分类表和自检表塞进博客正文。
- 用户要博客版时，只在同一份日志上调整标题、段落和必要背景，不自动变成长篇论说文。引用与个人推测分开，未核实的外部断言不能改写成已证实事实。
- 发现涉及隐私的细节时，给出具体待处理项或可选的匿名版本，不自行篡改真实经历；生成稿件不等于获准发布，不自动向博客上传或发帖。
- 输出文件遵守所在工作区约定，素材与日志产物不放回技能目录；没有既定约定时沿用用户项目位置。

用户说“直接整理”时一次完成；只有会实质改变内容的歧义才询问。用户要求分阶段时，再按“核对与归并 → 日志初稿 → 博客润色”推进，不预设每步都要确认。

## 交付前检查

1. 原稿的问题、想法、经历、情绪和发散都有落点吗？有价值的内容是否因“不像问题”而遗漏？
2. 每段是否能追溯到原稿？新增联想、待核实事实和用户自己的判断有没有混淆？
3. 第一人称、动机、不确定程度、矛盾与时间变化是否保留？
4. 是否过度拆分、强造标题、替用户下结论或加了没说过的计划？
5. 念出来像本人吗？正文能独立阅读，备注与发布内容分开了吗？
