# 从零散表达整理出思路线索

目标是帮助作者回看自己的思考，不是把材料切成可发布问题的数量清单。

1. 按源位置记录触发场景、问题、判断、感受、自我修正、联想和中断点。
2. 先依照思路推进顺序归组；同一对象在后文再次出现，回到原组补充，但保留“先前这样想，后来又怀疑”的变化。
3. 同一场景中的疑问、点子和情绪可以写在一节里。只有换成独立经历或独立主题才另起节。存疑则合，“另外”“还有”不构成拆分依据。
4. 不以是否有“核心矛盾”、需要哪类回答者或能否撑满三句话决定记录资格。短记录也能独立成段。
5. 保留发散的连接：从什么想到什么；原稿没说为什么，就用并列或“又想到”，不要补因果。
6. 已获认可的划分不要再拆。合并或拆分后按新的内容给真标题，不用“T1+T2”占位标签。

底稿可用 `源位置 / 内容 / 类型（可多选） / 去向`，无需每次展示。去向包括正文、并入哪节、保留为待续片段、确属无信息噪声。不要为每个语气词建立删除清单；实质删除或有争议的归并再说明。

日志顺序优先保留原始思路；跨日期材料先按日期再按主题。为可读性调换相邻段落可以，但不能伪造观点演化顺序。
