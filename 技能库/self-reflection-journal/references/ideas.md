# 想法、记录与发散

以下内容都可以进入日志，不是问题的东西也不是废料：

| 内容 | 写法 |
|---|---|
| 问题 | 保留作者在问什么，不代答；可以没有明显矛盾 |
| 主张或观察 | 保留“我觉得”“似乎”等限定，不变成公理 |
| 点子或方案 | 记清设想和已有步骤；没提出步骤就不补行动计划 |
| 经历、日常、情绪 | 说明原稿已有的场景与感受；不能只保留“有用结论” |
| 联想 | 保留作者联想到的对象，区分连续思路与独立岔路 |
| 没讲完的片段 | 原样保留可读部分，注明未完；不能因不成熟而删除 |
| 相反判断 | 都保留，写清先后或“我同时有两种感觉” |

同一节可以同时有这些内容，不要机械重复为四个区块。不要求想法去掉第一人称，不强制“建议去向”。

整理者自己的发散不是用户原有内容。只有用户要求“帮我再发散”时，才在正文外单列“整理者补充”，用可能、可探索等语气，不伪装成作者想法。
