# 想法、经历与发散如何进入文章

完整识别素材中的问题、主张、观察、设想、方案、经历、情绪、联想、未完成片段及相反判断。这些是工作底稿的分析维度，不是要求输出的清单或章节模板。

| 原有内容 | 成文时保留什么 |
|---|---|
| 问题 | 为什么开始困惑、还卡在哪里；不代答，不要求有核心矛盾 |
| 主张或观察 | “我觉得”“似乎”等确定程度，不变成公理 |
| 点子或方案 | 作者已有的设想与步骤；没提出计划就不补 |
| 经历、日常、情绪 | 具体场景与感受，不能只剩“有用结论” |
| 发散 | 从什么想到什么；没有因果就保留并列或“又想到” |
| 未完成片段 | 与主线相关的疑问和停顿；短素材不硬扩写 |
| 相反判断 | 真实先后或同时存在的两种感受，不替作者选一个最终立场 |

同一方向的内容自然融合为文章，不机械拆成四个区块，不要求想法去掉“我觉得”，不强制“建议去向”。技术思考与人生感慨适当分篇，作者明确建立的重要联系可保留。

识别价值与选入正文是两回事：情绪和未完成思考不因不成熟而被扔掉，但无关录音、转写、文件管理等枝节不必进文章，可以留底稿。素材只够一段时按短记录处理，不为了 2–4 篇的经验范围凑内容。

整理者自己的发散不属于作者。只有用户要求扩展时，才在正文外单列“整理者补充”，用可能、可探索等语气；不伪装成作者经历或结论。
