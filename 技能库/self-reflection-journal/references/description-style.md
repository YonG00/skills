# 保住思考的那个人

只做必要的去重复、顺序调整和可读性润色。保留第一人称、具体名词、真实场景、口语连接词、情绪和犹豫。

“脑子好像还没开机”不要换成“晨间认知功能激活滞后”；“我在考虑”不能变成“我决定了”。不要替用户补充没说过的澄清、免责、动机或经历。逐句问：原稿里找得到依据吗？找不到就删，或在用户要求扩展时明确放进补充部分。

允许少量小标题和列表帮助组织日志，不沿用旧版问题描述禁止小标题的约束；也不要把每一句变成结构化提纲。长短段落自然交替，不强制一句一段。

问题可以保持未解，观点可以暂时矛盾，记录可以只停留在感受。结尾不强制疑问句、总结或升华，不把“我还没想完”写成成功学感悟。

交付前念出来：这像作者会说的话吗？哪些词变成了报告腔？为了顺畅是否补了并不存在的因果？
