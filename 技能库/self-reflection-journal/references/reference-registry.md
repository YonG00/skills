# 来源与历史

| 来源 | 用途 | 边界 |
|---|---|---|
| 早期六轮提问整理反馈，摘录见 worked-example.md | 保留个人措辞、具体对象、避免过度拆分与补话 | 历史任务是平台提问，不代表当前输出格式 |
| 用户2026-10-26的范围调整 | 从个人录音和稿子提炼问题、想法、记录、发散，作为后续博客日志 | 当前技能定位，替代平台专属要求 |

早期案例只保留已有必要摘录，不增加私人原文。不要将本次用户的录音、生活细节或实际日志加入公开技能仓库。

与 conversation-synthesis 的区别：后者主要将长对话的讨论与判断变化综合成文章；本技能侧重个人日志，允许碎片、普通日常与没有结论的记录，不要求完成论证。
