# 转写保真

听错一个名称、漏掉一个“不”，就可能把整条思路整理反。核对对象包括关键名词、数字、否定词、断句和说话人归属。

- 有录音与稿子时，优先定位对应时间核对；不能播放或没有听过时，不声称已经听校。
- 明显标点和口头填充可修；专名有疑问时检查名称与语境，不仅判断它是否存在。
- 外部检索能提供候选拼写，不能证明用户实际说了哪一个。仍有多个候选或语义会变化时，询问或标“待确认”。
- 缺少联网或音频工具时，保留存疑词，不编造转写与依据；无关段落照常整理。
- 保留反复、自我纠正和犹豫带来的意义；单纯无信息的重复可合并。

有实质修改时，在正文后的整理备注列 `原文 / 处理 / 依据（录音时间、用户确认或外部候选）`。没核实就写没核实，不把不确定项当成后文论证的事实。
