| [lingbot-code-changes](lingbot-code-changes/) | 受控代码改动流程 |

## 维护方式

1. 在这里修改技能规则、组件和模板，保留来源与许可证。
2. 在 `资料/日期_时间_主题/` 建作品测试，数据和成片不加入 Git。
3. 验证后记录版本变化，再提交到当前 skills 仓库。
4. 需要让运行时采用修改时，将本地源码同步到实际安装目录；GitHub 更新与本机安装同步是两件事。
