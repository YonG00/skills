# 博客园发布（cnblogs-publisher）

检查指定文档、生成最终预览，等用户明确确认该版本后发布到博客园。支持 MetaWeblog 随笔和 PAT 批量文章、合集归属及回读核验。执行规则、参数和批量计划格式见 [SKILL.md](SKILL.md)。

## 凭据与运行

仅依赖 Python 标准库。令牌通过 `CNBLOGS_TOKEN` 环境变量提供；单篇脚本也支持终端隐藏输入。不要将令牌写进技能、命令参数或日志。默认博客为 `yong2333`，MetaWeblog 登录名为 `yong_2333`，两者不同。

- `scripts/cnblogs.py`：只读连接/分类查询、单篇预览、确认后发布与核验。
- `scripts/publish_batch.py`：整批 SHA256 确认后发布文章，加入指定合集并核验。异常后保留已创建 ID，拒绝盲目重试。
- `tests/`：离线测试确认门禁、修改检测、重复防护、写入异常和合集核验。

运行测试：`python3 -m unittest discover -s 技能库/cnblogs-publisher/tests -v`（仓库根目录）。

合集与传统分类分开查询。公开侧栏或 MetaWeblog 最近随笔列表不能直接当作全部文章数量。真实三篇文章的发布、正文回读、合集加入与公开页面访问已于 2026-10-26 验证；正文、预览、计划及发布记录保留在本地资料目录，不纳入 Git。

2026-10-28 补充：发布成功且合集核验通过后，公开页仍可能因「待审核」返回 404。用 `POST /openapi/v1/posts/reviewStatus:check`（PAT，`{"PostId": ...}`）确认状态；待审核不是失败，不要重发。合集名称会变，发布前重新查询当前标题。详见 [SKILL.md](SKILL.md#发布后核验与审核状态)。

当前不支持自动图片上传、远端草稿、文章修订或定时发布。安装时复制整个技能目录；仓库 push 不会自动同步本机运行时安装副本。
