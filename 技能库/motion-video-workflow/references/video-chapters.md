# 给已有视频划分章节

仅输出章节时，直接使用现有成片和时间轴，不重新合成、听写或渲染。制作视频或上传视频的权限也不能从章节请求中推断。

## 内容与时间

1. 按观众要定位的主题合并：问题、方法、关键机制、对比、实验与结论。制作时每6分钟一段只是交付单位，不能据此机械分章。
2. 本用户的 B 站交付默认**不超过10章，每个标题不超过16字**；当次要求优先。保守地将字母、数字、标点和空格都按一个字符计数。先满足约束再交付，避免先给二三十章或长标题，再让用户纠正。
3. 从**最终成片对应的合并时间轴**取主题开始时间，计入段间停顿、转场、增补内容等偏移。对于 `assembly.json`，可用 `part.global_start + unit.start`；不要直接沿用各段的局部秒数或按稿件字数估计。
4. 开头从零开始，后续时间严格递增，相邻章节至少5秒，均在成片时长内。整秒时间可向下取整以免切掉话题首字。超过一小时仍使用完整的 `HH:MM:SS`。
5. 如果成片经过剪辑，以剪辑后的文件或时间映射为准。找不到可核对的最终时间轴时，定位实际视频并检查边界，不能将未经核验的估计写成准确章节。

这些数量和标题要求来自用户偏好；不要将其表述为已经查证的平台固定上限。

## 可复用工具

先由内容判断选定主题与短标题，再用 `scripts/chapters.py` 检查并格式化。工具不替代语义划分。

```json
{"chapters": [
  {"start": 0, "title": "开场与问题"},
  {"start": "00:10:15", "title": "方法与原理"}
]}
```

```bash
python scripts/chapters.py chapters.json --duration 1200 --out 视频章节.txt
```

已有 `assembly.json` 与各段 `visual_plan.json` 时，条目可用 `{"unit": 49, "title": "方法与原理"}` 引用讲解单元，工具加上最终全局偏移。路径相对装配文件解析，也支持绝对路径。

```bash
python scripts/chapters.py chapters.json --assembly assembly.json --out 视频章节.txt
```

`--max-chapters`、`--max-title-length`、`--min-gap` 仅在用户当次要求不同约束时调整。交付一个可直接复制的纯文本代码块，每行 `HH:MM:SS 章节标题`，不在块内夹入编号或解释；可另存 UTF-8 TXT 到项目资料目录。这里的命令相对技能目录运行。
